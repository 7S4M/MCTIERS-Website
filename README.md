# MC TIERS Leaderboard

A simple leaderboard for Minecraft PvP players with different ranks and point systems.

## Features
- Add players with different ranks
- Automatic point calculation based on rank
- Leaderboard sorted by points
- Delete players
- Data saved in browser (localStorage)

## Ranks & Points
- LT5: 1 Point
- HT5: 2 Points
- LT4: 3 Points
- HT4: 4 Points
- LT3: 6 Points
- HT3: 10 Points
- LT2: 20 Points
- HT2: 30 Points
- LT1: 45 Points
- HT1: 60 Points
